# 🚌 Bharat Bus Simulator 3D

### Indian Bus Driving Simulator Game

Bharat Bus Simulator 3D is a browser-based bus driving game inspired by Indian roads and bus driving experiences.

🌐 **Play Game:** https://glittering-bublanina-3fe676.netlify.app/

## 🎮 About the Project

This project aims to provide an enjoyable 3D bus driving experience through a web browser.

Players can experience a bus simulator environment inspired by Indian transportation.

## ✨ Features

- 3D bus driving game experience
- Browser-based gameplay
- Indian bus simulator theme
- Playable through a public website
- Accessible on supported desktop and mobile browsers
